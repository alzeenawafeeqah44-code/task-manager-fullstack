# Full Stack Task Manager

A full-stack task manager application built using Node.js, Express, MySQL, HTML, CSS, and JavaScript.

## Features

* User Signup & Login
* Add Tasks
* Delete Tasks
* Persistent storage using MySQL

## Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express
* Database: MySQL

## How to Run

1. Start backend:
   node server.js
2. Open login.html
